## 🚀 使用方法

### **步骤 1：创建新文章**

1. 在 Obsidian 中打开 `content/blog/zh/` 或 `content/blog/en/` 文件夹
2. 创建新文件（建议用英文命名，如 `how-to-use-daysfromtoday.md`）
3. 使用快捷键插入模板：
   - Mac: `Cmd + P` → 输入 "Templater" → 选择 "Insert Template"
   - Windows: `Ctrl + P` → 输入 "Templater" → 选择 "Insert Template"
4. 选择 `blog-template-optimized` 模板

### **步骤 2：填写 Frontmatter**

模板会自动填充大部分信息，只需修改：

```yaml
---
title: "文章标题"  # 修改为实际标题
description: "文章描述"  # 修改为实际描述
category: "Blog"  # 可选：Blog/Guide/Story/Philosophy/Tools/Updates
tags: ["时间管理", "工具", "生活"]  # 修改为实际标签
featured: false  # 是否置顶
image: "/images/blog/文章slug.jpg"  # 图片路径
readingTime: "5 min read"  # 阅读时长
---
```

### **步骤 3：编辑内容**

1. **保留需要的组件**：根据文章类型保留相应部分
2. **删除不需要的组件**：直接删除不需要的整个章节
3. **填充内容**：在保留的组件中填写实际内容

### **步骤 4：添加图片**

1. 在文章中插入图片：直接拖拽图片到编辑器
2. 图片会自动上传到 R2 CDN
3. 链接会自动替换为 CDN 地址

### **步骤 5：发布前检查**

按照模板中的"写作检查清单"逐项检查：
- [ ] 内容质量检查
- [ ] SEO 优化检查
- [ ] 用户体验检查
- [ ] 技术检查

### **步骤 6：同步发布**

1. 保存文件
2. 运行同步命令：`npm run sync:obsidian`
3. 或使用实时监控：`npm run sync:obsidian:watch`

适用于：所有文章类型（增强可读性）

适用于：实用性文章、指南

适用于：专业文章、分析报告

适用于：教程、产品介绍

#### 8. 总结
适用于：所有文章（建议保留）
```markdown

2. ...
```

#### 9. 相关链接
适用于：所有文章（建议保留）
```markdown

- [内部链接](#)
- [外部资源](url)
```

适用于：学术性、专业性文章

#### 11. 图片区域
适用于：需要配图的文章
```markdown

```

#### 12. 互动区域
适用于：鼓励互动的文章
```markdown

```

## ⚙️ 高级技巧

### **1. 自定义 Category**
根据内容类型修改 `category` 字段：
- `Blog` - 一般博客文章
- `Guide` - 使用指南
- `Story` - 个人故事
- `Philosophy` - 哲学思考
- `Tools` - 工具介绍
- `Updates` - 产品更新

### **2. 标签策略**
建议使用 3-5 个标签：
- 1 个主要标签（内容类别）
- 2-3 个次要标签（具体话题）
- 1 个长尾标签（特定关键词）

示例：
```yaml
tags: ["时间管理", "工具", "日期计算", "生活技巧"]
```

### **3. SEO 优化**
- **标题**：30-60 字符，包含主关键词
- **描述**：120-160 字符，包含次关键词
- **图片 alt**：描述性文字，包含关键词
- **内部链接**：至少 2-3 个内部链接

### **4. 阅读时长计算**
- 中文：300-400 字/分钟
- 英文：200-250 词/分钟

示例：
- 1500 字中文文章 ≈ 5 min read
- 2000 字中文文章 ≈ 7 min read

## 🚨 常见问题

### Q1: 模板太长了，能简化吗？
A: 可以！这是一个"全功能"模板，根据需要删除不需要的组件即可。建议保留：摘要、正文、总结、相关链接。

### Q2: 如何快速删除不需要的组件？
A: 直接选中整个章节（包括标题和内容）按 Delete 删除即可。

### Q3: 图片路径怎么设置？
A: 直接拖拽图片到编辑器，系统会自动上传到 R2 并生成正确的 CDN 链接。

### Q4: 如何同步到网站？
A: 保存文件后运行 `npm run sync:obsidian` 或使用实时监控 `npm run sync:obsidian:watch`。

### Q5: 模板中的注释需要删除吗？
A: 是的，发布前请删除所有 `<!-- 注释内容 -->` 和"写作备注"部分。
