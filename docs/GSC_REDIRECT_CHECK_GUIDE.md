# 🔍 GSC 查看域名重定向状态 - 可视化指南

## 🎯 问题
在 GSC 中如何确认 `14daysfromtoday.com` 和 `daysfromday.com` 已重定向到 `www.daysfromtoday.ai`？

---

## 📋 三种方法对比

| 方法 | 推荐度 | 速度 | 详细程度 | 适用场景 |
|------|--------|------|----------|----------|
| ⭐ **方法1：设置页面** | ⭐⭐⭐⭐⭐ | 快 | 中 | 日常检查、快速确认 |

## ⭐ 方法1：设置页面（最推荐）

### 📍 导航路径
```

  ↓
左上角资源选择器（下拉菜单）
  ↓

  ↓

## 🔍 方法2：URL 检查工具（最详细）

### 📍 导航路径
```
Google Search Console 首页
  ↓
左上角选择资源 "daysfromday.com" 或 "14daysfromtoday.com"
  ↓

### ⚡ 优势
- **立即测试**：点击"测试实际 URL"可以实时检查
- **最详细**：显示 HTTP 状态码、重定向目标等
- **无需等待**：不依赖 Google 的定期爬取

## ⚠️ 故障排查

### 情况1：刚刚验证域名（< 3 天）

**现象：**
- "设置页面" 还不显示重定向信息
- "覆盖率报告" 还没有数据

**解决方案：**
✅ **这是正常的！**
- 使用 **"URL 检查工具"** + **"测试实际 URL"** 立即验证
- 等待 2-3 天后再查看 "设置页面"
- 可选：点击 "请求编入索引" 加速

### 情况2：超过 7 天还没显示

**现象：**
- 所有方法都不显示重定向信息
- 或显示错误信息

**排查步骤：**
1. 命令行检查重定向是否工作：
   ```bash
   curl -I https://daysfromday.com
   curl -I https://14daysfromtoday.com
   ```
   应该看到 `HTTP/2 301` 和 `Location: https://www.daysfromtoday.ai/`

2. 检查 Vercel 配置
   - 确认域名已添加
   - 确认重定向规则正确

3. 检查 GSC "抓取错误" 报告
   - 左侧菜单 → "设置" → "抓取统计信息"
   - 查看是否有错误
