## 🎯 Day 0：前置准备清单（预计 8 小时）

### 1. Git 分支准备
```bash
git checkout main && git pull origin main
git checkout -b develop
git push -u origin develop
```

### 2. Supabase 配置
- [ ] 访问 https://supabase.com 创建项目
- [ ] 记录 URL、Anon Key、Service Role Key
- [ ] 添加到 `.env.local`
- [ ] 安装依赖：`npm install @supabase/supabase-js @supabase/ssr`

### 3. Cloudflare Workers KV
- [ ] 创建 KV Namespace：`daysfromtoday-short-links`
- [ ] 安装 Wrangler：`npm install -g wrangler`
- [ ] 登录：`wrangler login`
- [ ] 创建 Worker 项目（见详细文档）

### 4. Vercel Edge Config
- [ ] 在 Vercel Dashboard 创建 Edge Config
- [ ] 初始配置：`{ "rollout_percentage": 0 }`
- [ ] 安装依赖：`npm install @vercel/edge-config`

### 5. 核心依赖安装
```bash
npm install @vercel/og react-hook-form zod framer-motion nanoid sharp @upstash/ratelimit @upstash/redis
npm install -D vitest @playwright/test @lhci/cli @testing-library/react
```

### 6. 监控工具
- [ ] Sentry：`npx @sentry/wizard@latest -i nextjs`
- [ ] Upstash Redis：访问 https://upstash.com 创建数据库

### 7. 环境变量模板
```bash
# .env.local
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
CLOUDFLARE_ACCOUNT_ID=
CLOUDFLARE_KV_NAMESPACE_ID=
CLOUDFLARE_API_TOKEN=
EDGE_CONFIG=
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=
NEXT_PUBLIC_SENTRY_DSN=
```

## 🔴 关键风险与应对

| 风险 | 等级 | 应对措施 |
|------|------|---------|
| **数据同步失败** | 🔴 高 | 双写期（2 周）+ 数据校验 + 保留 LocalStorage 30 天 |
| **Supabase 服务中断** | 🔴 高 | Local-first 备用方案 |
| **@vercel/og 性能下降** | 🟡 中 | 增加缓存层 + 监控生成时间 |
| **sharp 库失败** | 🟡 中 | `vercel.json` 配置 `includeFiles` |

## 📝 每日工作流

### 开发阶段
```bash
# 1. 创建功能分支
git checkout develop
git checkout -b feature/[功能名]

# 2. 开发 + 测试
npm run dev
npm run type-check
npm run lint
npm run test

# 3. 提交代码
git add .
git commit -m "feat: [功能描述]"
git push origin feature/[功能名]

# 4. 创建 PR
# 在 GitHub 创建 PR：feature/[功能名] → develop
```

### 合并到 develop
```bash
# PR 通过 Code Review 后
git checkout develop
git pull origin develop
git checkout main
git merge develop
git push origin main
```

### 发布到生产环境
```bash
# 通过 Vercel Dashboard 或 CLI
vercel --prod
```
