## 📝 内容管理流程

### 旧流程（博客 - 繁琐）
```
Obsidian 编辑
  ↓ 手动上传图片
  ↓ 运行同步脚本
  ↓ 重新构建
  ↓ 提交部署
```

### 新流程（Wish Books - 简单）
```
Web 后台编辑
  ↓ 拖拽上传图片
  ↓ 一键发布
  ↓ 自动生成静态页面
✅ 完成！
```

**时间节省**：从 30 分钟 → 2 分钟

## 📋 10个内容模块（详情页）

1. **Hero Section** - 标题、标签、统计、CTA
2. **故事引入** - 500-800 字引发共鸣
3. **路线图** - Timeline 时间线
4. **真实案例** - 3 个参考案例
5. **AI 建议** - V3.2 助手集成
6. **资源清单** - 工具、应用、课程、书籍
7. **FAQ** - 5-8 个常见问题
8. **延伸阅读** - 3-5 个相关卡片
9. **CTA** - 创建我的计划（跳转 Wishlist）
10. **JSON-LD** - SEO 结构化数据

## 🎨 后台功能（管理员）

### 卡片列表页
```
/admin/wish-books
- 表格展示所有卡片
- 筛选：状态、类别、时间维度

- 操作：编辑、删除、发布
```

```
/admin/wish-books/new
/admin/wish-books/[id]/edit

【基础信息】
- 标题、副标题、slug
- 时间维度、类别、难度
- 封面图

【富文本编辑器】
- 故事引入（Markdown/HTML）
- 拖拽上传图片

【结构化内容】
- 路线图（JSON）
- 真实案例（JSON）
- AI 建议（JSON）
- 资源清单（JSON）
- FAQ（JSON）

【SEO】
- Meta 标题
- Meta 描述
- 关键词

【操作】
- 保存草稿
- 预览
- 发布
```

## 💡 关键决策点

### ✅ 已确定
1. **两层架构**（聚合页 + 详情页）
2. **简单后台**（Web UI，基于 Tiptap）
3. **静态生成**（SSG + ISR）
4. **Supabase 数据库**（不用 Contentlayer）
