```typescript
interface DifficultyAssessment {
  score: number;        // 综合难度分数 (0-100)
  level: 'easy' | 'medium' | 'hard' | 'extreme';
  factors: {
    timeSpan: number;      // 时间跨度因素 (25%)
    complexity: number;    // 目标复杂度 (25%)
    ambiguity: number;     // 目标模糊度 (25%)
    challenge: number;     // 挑战性 (25%)
  };
}
```

#### 评分规则

##### 1. 时间跨度因素 (timeSpan)

```typescript
// 基于天数的梯度评分
if (days <= 30) return 30;         // 短期目标，相对容易
if (days <= 60) return 50;         // 中短期
if (days <= 100) return 70;        // 中长期
return 90;                         // 长期目标，难度高
```

##### 2. 目标复杂度 (complexity)

```typescript
// 基于关键词的复杂度判断
const complexWords = ['建立', '创建', '系统', '完整', '全面', '深入', '精通'];
const simpleWords = ['了解', '学习', '尝试', '开始', '初步'];

// 计算匹配关键词数量，映射到 0-100 分
```

##### 3. 目标模糊度 (ambiguity)

```typescript
// 越具体，分数越低；越模糊，分数越高
const specificWords = ['完成', '达到', '实现', '具体的', '明确的'];
const vagueWords = ['更好', '提升', '改善', '成长'];

// 具体目标：30-40 分
// 模糊目标：60-80 分
```

##### 4. 挑战性 (challenge)

```typescript
// 基于目标本身的挑战性
const highChallengeWords = ['创业', '转行', '突破', '改变', '创新'];
const lowChallengeWords = ['保持', '维持', '继续', '巩固'];

// 高挑战：70-90 分
// 低挑战：20-40 分
```

#### 难度等级划分

```typescript
综合分数 0-30:   'easy'     (简单)
综合分数 31-60:  'medium'   (中等)
综合分数 61-85:  'hard'     (困难)
综合分数 86-100: 'extreme'  (极难)
```

#### 应用场景

- ✅ AI 助手人格匹配（难度越高，匹配越专业的助手）
- ✅ Prompt 模板选择（不同难度使用不同策略）
- ✅ 任务分解粒度（难度越高，任务越细）
- ✅ 方法论推荐（匹配合适的科学方法）

##### 匹配规则

```typescript
interface PersonaMatchingRule {
  // 1. 基于目标类型的匹配
  goalTypeMapping: {
    'fitness': 'coach',           // 健身 → 教练型
    'learning': 'mentor',         // 学习 → 导师型
    'entrepreneurship': 'strategist', // 创业 → 战略型
    'relationship': 'companion',  // 关系 → 陪伴型
    // ...
  };
  
  // 2. 基于难度的调整
  difficultyAdjustment: {
    'easy': 'companion',      // 简单目标 → 陪伴型
    'medium': '保持类型映射',  // 中等难度 → 按类型匹配
    'hard': 'mentor',         // 困难目标 → 导师型
    'extreme': 'strategist'   // 极难目标 → 战略型
  };
  
  // 3. 用户偏好优先
  if (userPreferred) return userPreferred;
}
```

##### 匹配算法

```typescript
export async function matchPersona(
  goalType: string,
  difficulty: DifficultyLevel,
  userPreferred?: string
): Promise<AIPersona> {
  // 1. 优先使用用户偏好
  if (userPreferred) {
    const preferred = await getPersona(userPreferred);
    if (preferred) return preferred;
  }
  
  // 2. 基于目标类型匹配
  const typeBasedPersona = goalTypeMapping[goalType];
  
  // 3. 基于难度调整
  if (difficulty === 'extreme') {
    return getPersona('strategist');
  } else if (difficulty === 'easy') {
    return getPersona('companion');
  }
  
  // 4. 返回匹配结果
  return getPersona(typeBasedPersona) || getPersona('companion');
}
```

#### 匹配算法

##### 评分维度（总分 140 分）

```typescript
1. 目标类型匹配 (0-40 分)
   - 完全匹配：40 分
   - 部分匹配：20 分
   - 不匹配：0 分

2. 难度等级匹配 (0-40 分)
   - 完全匹配：40 分
   - 相邻等级：20 分
   - 不匹配：0 分

3. 时间跨度匹配 (0-30 分)
   - 短期（< 30 天）：适合原子习惯、番茄工作法
   - 中期（30-100 天）：适合 SMART、渐进式超负荷
   - 长期（> 100 天）：适合 OKR、刻意练习

4. 关键词匹配 (0-30 分)
   - 每个关键词命中：5 分
   - 最多：30 分
```

##### 匹配流程

```typescript
export async function matchMethodology(
  params: {
    goalType: string;
    difficulty: string;
    timeSpan: number;
    goalText?: string;
  }
): Promise<Methodology[]> {
  // 1. 从数据库查询所有方法论
  const allMethodologies = await fetchMethodologies();
  
  // 2. 对每个方法论计算匹配分数
  const scored = allMethodologies.map(m => ({
    methodology: m,
    score: calculateMatchScore(m, params)
  }));
  
  // 3. 按分数排序，返回前 2-3 个
  return scored
    .sort((a, b) => b.score - a.score)
    .slice(0, 3)
    .map(s => s.methodology);
}
```

## 🎓 七、方法论体系

### 7.1 内置的 8 种科学方法论

#### 1. 渐进式超负荷 (Progressive Overload)

```
适用场景：健身、技能训练
核心原理：逐步增加强度，突破适应期
实施步骤：
1. 评估当前基线能力
2. 设定 10-15% 的递增计划
3. 每 1-2 周增加强度
4. 监控进度并调整
```

#### 2. 费曼学习法 (Feynman Technique)

```
适用场景：学习、知识掌握
核心原理：讲解是最好的学习
实施步骤：
1. 学习目标概念
2. 用简单语言讲解给别人
3. 识别讲解中的盲区
4. 回到材料重新学习
5. 简化和类比
```

#### 3. 原子习惯法 (Atomic Habits)

```
适用场景：习惯养成、行为改变
核心原理：1% 的改进，身份认同
实施步骤：
1. 明显化：让习惯显而易见
2. 吸引人：让习惯有吸引力
3. 容易做：让习惯容易执行
4. 有满足感：让习惯令人满意
```

#### 4. SMART 目标法

```
适用场景：通用目标设定
核心原理：具体、可衡量、可达成、相关、有时限
实施步骤：
1. Specific - 具体化目标
2. Measurable - 设定可量化指标
3. Achievable - 确保可达成
4. Relevant - 与长期目标相关
5. Time-bound - 设定明确期限
```

#### 5. GTD (Getting Things Done)

```
适用场景：时间管理、任务管理
核心原理：外部化思考，清空大脑
实施步骤：
1. 捕获：所有事项写下来
2. 理清：判断是否可行动
3. 组织：分类到清单
4. 回顾：定期检视
5. 执行：根据情境选择行动
```

#### 6. OKR (Objectives and Key Results)

```
适用场景：创业、团队目标、季度规划
核心原理：目标 + 关键结果
实施步骤：
1. 设定 1-3 个核心目标 (Objective)
2. 为每个目标设定 2-5 个关键结果 (KR)
3. 确保 KR 可量化
4. 设定挑战性（70% 完成度为优秀）
5. 定期回顾和调整
```

#### 7. 番茄工作法 (Pomodoro)

```
适用场景：专注、时间管理
核心原理：专注 25 分钟 + 休息 5 分钟
实施步骤：
1. 选择一个任务
2. 设定 25 分钟计时器
3. 专注工作，不被打断
4. 休息 5 分钟
5. 每 4 个番茄后休息 15-30 分钟
```

#### 8. 刻意练习 (Deliberate Practice)

```
适用场景：技能精进、专业提升
核心原理：目标导向、走出舒适区、即时反馈
实施步骤：
1. 明确具体的技能目标
2. 专注于弱点和难点
3. 获得即时反馈
4. 反复练习直到掌握
5. 不断提高难度
```
