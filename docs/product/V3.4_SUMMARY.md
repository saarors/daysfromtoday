## 🏗️ 核心功能

### 1. 愿望卡片聚合页
**URL**：`/zh/wish-books`

**功能**：
- 卡片网格展示（响应式：1/2/3 列）
- 按时间维度筛选（7天、30天、90天...5年）
- 按类别筛选（健身、学习、职业等 8 个类别）
- 全文搜索
- 排序（最新、最热、质量分）

---

### 2. 愿望卡片详情页
**URL**：`/zh/wish-books/[slug]`（如：`/zh/wish-books/100-days-marathon`）

**内容模块**：
1. Hero Section（标题、副标题、标签、统计、CTA）
2. 故事引入（500-800字）
3. 路线图（Timeline）
4. 真实案例（Gallery）
5. AI 助手建议（V3.2 集成）
6. 资源清单（工具、应用、课程、书籍）
7. FAQ（Accordion）
8. 延伸阅读（相关卡片）

**SEO**：
- 动态 Meta 标签
- JSON-LD（Article + FAQPage）
- Canonical + hreflang

---

### 3. 简单内容管理后台
**URL**：`/admin/wish-books`

**功能**：
- ✅ 卡片列表（表格展示，支持筛选）
- ✅ 创建/编辑表单（结构化字段）
- ✅ 富文本编辑器（Tiptap v2）
  - 标题、加粗、斜体、列表
  - 图片拖拽上传（自动上传到 R2）
  - 视频 URL 嵌入
- ✅ 预览功能（实时预览最终效果）
- ✅ 保存草稿 / 一键发布
- ✅ 发布后自动生成静态页面（ISR）

**优势**：
- ❌ 不需要 Obsidian
- ❌ 不需要手动上传图片
- ❌ 不需要运行脚本
- ✅ Web 界面，随时随地编辑
- ✅ 所见即所得

## 🛠️ 技术方案

### 技术架构

```
用户访问
    ↓
Next.js 15 (SSG + ISR)
    ↓
┌──────────────┬──────────────┐
│   聚合页      │   详情页      │
│  (静态生成)   │  (静态生成)   │
└──────────────┴──────────────┘
    ↓
管理后台
/admin/wish-books
    ↓
┌──────────────┬──────────────┐
│  Supabase    │ Cloudflare R2│
│  (数据库)     │ (图片/视频)   │
└──────────────┴──────────────┘
```

### 核心技术

| 层级 | 技术 |
|------|------|
| 前端框架 | Next.js 15 (App Router) |
| 富文本编辑器 | Tiptap v2 |
| 数据库 | Supabase PostgreSQL |
| 文件存储 | Cloudflare R2 |
| 部署 | Vercel Edge Functions |

### 关键特性

- ✅ **100% 静态生成**（SSG + ISR）
- ✅ **SEO 友好**（动态 Meta + JSON-LD）
- ✅ **性能优异**（LCP < 2s）
- ✅ **成本可控**（< $10/月）

## 📊 数据库设计

### 主表：`wish_books`

**核心字段**：
- 基础信息：`id`, `title`, `subtitle`, `slug`
- 维度分类：`time_dimension`, `category`, `difficulty`
- 内容字段：`content_html`, `content_json` (Tiptap)
- 结构化内容：`roadmap`, `real_cases`, `ai_suggestions`, `resources`, `faqs`
- 图片媒体：`cover_image_url`, `hero_image_url`, `og_image_url`
- SEO：`meta_title`, `meta_description`, `keywords`
- 统计：`view_count`, `save_count`, `share_count`
- 状态：`status` ('draft' | 'published' | 'archived')

**详见**：`V3.4_WISH_BOOKS_TECH_SPEC.md` 第二章

## 🎯 与现有功能的关系

### 功能集成

```
首页（日期计算）
    ↓ "100天后能做什么？"
Wishlist（AI 目标规划）
    ↓ "分享我的计划"
Wish Books（目标百科）← V3.4 新增
    ↓ "创建我的计划"
返回 Wishlist
```

### 关键差异

| 维度 | Wishlist | Wish Books |
|------|----------|-----------|
| **性质** | 个人的、临时的 | 公共的、永久的 |
| **生成方式** | AI 动态生成 | 人工策展 + AI 辅助 |
| **存储** | 用户数据库 | 内容数据库 |
| **SEO** | 不索引 | 100% 索引 |
| **目标** | 个性化计划 | 参考案例库 |

## 🔐 风险与约束

### 技术风险

| 风险 | 缓解措施 |
