## 一、产品概述

### 1.1 产品愿景

**从"日期计算工具"到"AI 陪伴式目标实现平台"**

DaysFromToday V3.0 将完成产品的核心转型：
- **V2.x**: 工具型产品（计算日期）
- **V3.0**: 情感化平台（AI 陪伴实现目标）

### 1.2 核心 Slogan

**主标题**: Days From Today  
**副标题**: 让 AI 陪伴你实现未来的目标  
**说明文字**: 简单和强大的日期计算工具，有趣的 AI 陪伴你实现目标

### 1.3 目标用户

| 用户类型 | 使用场景 | 核心需求 |
|---------|---------|---------|
| **个人成长型** | 学习计划、健身目标、职业转型 | AI 陪伴 + 目标分解 + 阶段性建议 |
| **学生群体** | 考试倒计时、毕业规划 | 时间规划 + AI 学习建议 |
| **生活记录型** | 纪念日、人生里程碑 | 情感连接 + AI 温暖陪伴 |
| **SEO 流量用户** | 快速查询日期 | 保留简单计算功能 |

### 1.4 产品差异化

| 竞品 | 定位 | 我们的优势 |
|------|------|-----------|
| ChatGPT | 通用 AI 对话 | ✅ 专注目标实现 + 时间维度 |
| Days Matter | 倒计时工具 | ✅ AI 陪伴 + 目标分解 |
| Notion | 项目管理 | ✅ 超轻量 + 情感化 |

## 二、产品定位变化

### 2.1 功能矩阵对比

| 维度 | V2.x | V3.0 |
|------|------|------|
| **核心定位** | 日期计算工具 | AI 陪伴式目标实现平台 |
| **主要入口** | 日期计算页 | 首页 Hero 大输入框 |
| **交互方式** | 表单填写 | 对话式 + AI 建议 |
| **内容生成** | 用户手动 | AI 辅助生成 |
| **情感连接** | 功能性 | 情感化 + 激励性 |
| **变现模式** | AdSense | AdSense + AI 服务 + Pro 会员 |
| **SEO 策略** | 保留 | **保留日期计算页面（SEO 核心）** |

### 2.2 用户旅程对比

**V2.x 用户旅程**:
```
选择日期 → 查看结果 → 离开/分享
```

**V3.0 用户旅程（主流程）**:
```
首页输入目标 → AI 对话分析 → 生成愿望卡片 → 愿望清单管理 → 定期回顾
        ↓
    AI 角色陪伴（Twinkle/Labubu/Jobs）
```

**保留的简单旅程（SEO）**:
```
日期计算页 → 查看结果 → 【可选】进入 AI 目标设定
```

#### 4.1.2 关键设计要点

1. **大输入框**：
   - 类似 ChatGPT 的体验
   - 支持多行文本，高度自适应
   - 实时字数统计（0/5000）
   - 超出限制时禁用提交按钮

2. **溢出提醒**：
   - 天数超出 10000：「你想穿越到未来 300 年吗？😄」
   - 输入负数：「时光机还在研发中哦~ 😉」
   - 选择过去日期：「让我们专注未来，一起创造美好！✨」

3. **AI 助手可视化**：
   - 大头像 + 名字
   - 简短人设描述（Hover 显示）
   - 选中状态高亮

4. **精选故事卡片**：
   - 包含：AI生成图、用户头像、目标时间、距今天数、工作日、目标描述、AI头像、AI昵称、AI建议
   - 卡片支持 hover 放大效果
   - 点击跳转到详情页

## 五、AI 集成方案

### 5.1 AI 服务商选择

| 服务商 | 用途 | 成本 | 优势 |
|-------|------|------|------|
| **DeepSeek** | 主要 AI（对话、分析） | 极低 | 🎯 性价比高，中文友好 |
| **OpenAI GPT-4o** | 备用方案 | 中等 | ✅ 质量稳定，英文强 |
| **DALL-E 3** | AI 生成图 | 固定 | ✅ 官方支持，效果好 |

**决策**:
- 默认使用 **DeepSeek**（成本最优）
- 复杂场景或高质量需求可切换到 **GPT-4o**
- 图片生成统一使用 **DALL-E 3**

## 九、成本优化策略

### 9.1 AI 调用成本

#### 9.1.1 DeepSeek 定价（估算）

- 输入: $0.001 / 1K tokens
- 输出: $0.002 / 1K tokens

#### 9.1.2 单次对话成本估算

```
用户输入: 500 tokens (约 5000 字中文)
AI 输出: 800 tokens (约 800 字中文)

成本 = (500 * 0.001 + 800 * 0.002) / 1000
     = $0.0021
     ≈ ¥0.015 / 次
```

#### 9.1.3 月度成本预估

**假设**:
- 每天 1000 次对话
- 月成本: 1000 × 30 × 0.0021 = **$63 ≈ ¥450**

---

### 9.2 图片生成成本

#### 9.2.1 DALL-E 3 定价

- Standard quality: $0.040 / 张
- HD quality: $0.080 / 张

#### 9.2.2 策略

- 默认 Standard（节省成本）
- Pro 用户可选 HD

#### 9.2.3 月度成本预估

**假设**:
- 每天 300 张图
- 月成本: 300 × 30 × 0.04 = **$360 ≈ ¥2600**
