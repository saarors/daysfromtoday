## 二、核心问题与需求

### 2.1 核心问题

**P0 级问题 (必须解决)**:
1. 🔴 **任务分解不智能**: 无法根据目标类型生成个性化任务列表
2. 🔴 **方法论缺失**: 没有专业的目标达成框架支撑

**P1 级问题 (重要优化)**:
3. 🟡 **Prompt 硬编码**: 数据库覆盖率低，修改成本高
4. 🟡 **助手配置静态**: 无法动态调整助手能力和定位

### 2.2 产品需求

**需求 1: 动态任务分解系统**
- **输入**: 目标文本 + 目标类型 + 难度等级
- **输出**: 3-5 个个性化的具体任务步骤
- **示例**:
  ```
  目标: "每天 50 个俯卧撑"
  任务:
  1. 评估当前体能基线
  2. 制定 4 周渐进式训练计划
  3. 设置每日提醒和打卡机制
  4. 准备必要的辅助装备
  ```

**需求 2: 方法论库系统**
- **库容量**: 8-10 种专业方法论
- **覆盖领域**:
  - 健身: 渐进式超负荷、FITT 原则
  - 学习: 费曼学习法、间隔重复
  - 习惯: 原子习惯、微习惯
  - 项目: SMART 目标、OKR
  - 技能: 刻意练习、1万小时定律
- **使用方式**: 根据目标类型自动匹配方法论 Prompt

**需求 3: Prompt 智能管理系统**
- **三层架构**:
  1. **Database Layer**: 存储 Prompt 模板和方法论
  2. **Composer Layer**: 智能组装 Prompt
  3. **Manager Layer**: 后台管理界面 (V3.2 实现)
- **核心能力**:
  - 支持模板变量 (`{goalText}`, `{days}`, `{methodology}`)
  - 支持多语言 (中/英)
  - 支持版本管理
  - 支持降级策略 (数据库 → 硬编码)

### 4.2 核心模块设计

#### 模块 1: PromptComposer (Prompt 组装器)

**职责**: 智能组装最终的 AI Prompt

**输入参数**:
```typescript
interface ComposePromptParams {
  goalType: string;        // 'fitness', 'learning', ...
  difficulty: string;      // 'easy', 'medium', 'hard', 'expert'
  language: 'zh' | 'en';
  stage: 'intro' | 'analysis' | 'task-decomposition';
  variables: {
    goalText?: string;
    days?: number;
    targetDate?: string;
  };
}
```

**输出**:
```typescript
interface ComposedPrompt {
  systemPrompt: string;      // 系统提示词
  userPrompt: string;        // 用户提示词
  methodology?: {
    name: string;
    description: string;
    principles: string[];
  };
  temperature: number;       // 推荐温度
  max_tokens: number;        // 推荐 token 数
}
```

**核心逻辑**:
```typescript
async function composePrompt(params: ComposePromptParams): Promise<ComposedPrompt> {
  // 1. 查询 Prompt 模板
  const template = await getPromptTemplate(params);
  
  // 2. 查询方法论
  const methodology = await getMethodology(params.goalType, params.difficulty);
  
  // 3. 组装基础 Prompt
  let systemPrompt = template.system_prompt;
  let userPrompt = template.user_prompt;
  
  // 4. 注入方法论
  if (methodology) {
    systemPrompt = injectMethodology(systemPrompt, methodology);
  }
  
  // 5. 变量替换
  systemPrompt = replaceVariables(systemPrompt, params.variables);
  userPrompt = replaceVariables(userPrompt, params.variables);
  
  // 6. 返回组装结果
  return {
    systemPrompt,
    userPrompt,
    methodology,
    temperature: template.temperature || 0.7,
    max_tokens: template.max_tokens || 2000,
  };
}
```

**降级策略**:
```typescript
async function getPromptTemplate(params: ComposePromptParams): Promise<Template> {
  try {
    // 1. 尝试从数据库获取
    const dbTemplate = await supabase
      .from('ai_prompt_library')
      .select('*')
      .eq('goal_type', params.goalType)
      .eq('difficulty', params.difficulty)
      .eq('language', params.language)
      .eq('stage', params.stage)
      .single();
    
    if (dbTemplate.data) return dbTemplate.data;
    
    // 2. 降级: 查找通用模板 (goal_type = 'general')
    const generalTemplate = await supabase
      .from('ai_prompt_library')
      .select('*')
      .eq('goal_type', 'general')
      .eq('stage', params.stage)
      .single();
    
    if (generalTemplate.data) return generalTemplate.data;
    
    // 3. 最终降级: 使用硬编码
    return getHardcodedPrompt(params);
    
  } catch (error) {
    console.error('Prompt 获取失败，使用硬编码:', error);
    return getHardcodedPrompt(params);
  }
}
```

**实现逻辑**:
```typescript
export async function POST(request: Request) {
  const { goalText, goalType, difficulty, days, language } = await request.json();
  
  // 1. 获取任务分解 Prompt
  const prompt = await composePrompt({
    goalType,
    difficulty,
    language,
    stage: 'task-decomposition',
    variables: { goalText, days }
  });
  
  // 2. 调用 DeepSeek 生成任务列表
  const response = await fetch('https://api.deepseek.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${process.env.DEEPSEEK_API_KEY}`
    },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [
        { role: 'system', content: prompt.systemPrompt },
        { role: 'user', content: prompt.userPrompt }
      ],
      temperature: 0.7,
      max_tokens: 500
    })
  });
  
  const data = await response.json();
  
  // 3. 解析任务列表
  const tasks = parseTaskList(data.choices[0].message.content);
  
  // 4. 返回结果
  return NextResponse.json({
    tasks,
    methodology: prompt.methodology,
    estimatedTime: estimateTime(tasks.length)
  });
}
```

#### 模块 3: MethodologyMatcher (方法论匹配器)

**职责**: 根据目标类型和难度匹配最佳方法论

**核心逻辑**:
```typescript
async function getMethodology(
  goalType: string, 
  difficulty: string
): Promise<Methodology | null> {
  
  // 1. 查询方法论库
  const { data } = await supabase
    .from('methodology_library')
    .select('*')
    .contains('applicable_goal_types', [goalType])
    .gte('min_difficulty_level', difficultyToLevel(difficulty))
    .lte('max_difficulty_level', difficultyToLevel(difficulty))
    .eq('is_active', true)
    .order('priority', { ascending: false })
    .limit(1)
    .single();
  
  return data;
}

function difficultyToLevel(difficulty: string): number {
  const map = { easy: 1, medium: 2, hard: 3, expert: 4 };
  return map[difficulty] || 2;
}
```

async function generateTaskList() {
  if (!goalData || tasksLoading) return;
  
  setTasksLoading(true);
  
  try {
    const response = await fetch('/api/ai/task-decomposition', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        goalText: goalData.goalText,
        goalType: matchResult?.goalType.code || 'general',
        difficulty: matchResult?.difficulty || 'medium',
        days: goalData.days,
        language: locale
      })
    });
    
    const data = await response.json();
    
    if (data.success) {
      setDynamicTasks(data.data.tasks);
      // 可选：保存方法论信息
      setMethodology(data.data.methodology);
    } else {
      // 降级：使用默认任务
      setDynamicTasks(getDefaultTasks());
    }
    
  } catch (error) {
    console.error('任务生成失败:', error);
    setDynamicTasks(getDefaultTasks());
  } finally {
    setTasksLoading(false);
  }
}
