## 🚀 安装步骤

### 1. 启用社区插件
1. 打开 Obsidian 设置
2. 进入 "第三方插件"
3. 关闭 "安全模式"
4. 点击 "浏览"

### 2. 安装插件
1. 搜索插件名称
2. 点击 "安装"
3. 点击 "启用"
4. 配置插件设置

### 3. 配置插件
1. 进入插件设置
2. 根据需求调整配置
3. 设置快捷键
4. 测试功能

## ⚠️ 注意事项

### 性能考虑
- 不要安装过多插件
- 定期清理不用的插件
- 注意插件兼容性

### 备份建议
- 定期备份 `.obsidian` 文件夹
- 导出插件配置
- 记录自定义设置
