## 🎯 使用指南

### **现在如何使用模板**

1. **创建新文章**：
   - 在 Obsidian 中创建新文件
   - 使用 Templater 插入 `blog-template-optimized` 模板

2. **选择文章类型**：
   - 根据文章类型删除不需要的组件
   - 保留适合的组件结构

3. **快速开始**：
   - 博客文章：保留摘要、正文、总结
   - 使用指南：保留摘要、解决方案、行动建议
   - 个人故事：保留摘要、背景、正文、总结

### **模板组件说明**

**必需组件**（建议保留）：
- ✅ Frontmatter

**可选组件**（按需保留）：
