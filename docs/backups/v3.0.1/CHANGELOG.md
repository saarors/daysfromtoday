# V3.0.1 变更日志

**发布日期**: 2025-11-04

## 🐛 Bug 修复

### 关键修复

1. **修复 AI 内容保存时截断** (app/[locale]/wishlist/page.tsx)
   - 移除重复调用 `finishStreaming()`
   - 使用 `snapshotContent()` 直接读取内容
   - 确保数据完整性: Chat (892) = 数据库 (892) = 详情页 (892)

2. **修复详情页使用流式输出导致截断** (app/[locale]/wishlist/page.tsx)
   - 新增 `viewOnlyContent` 状态
   - 分离 Chat 和详情页的渲染逻辑
   - 详情页不再使用流式缓冲区

3. **修复详情页刷新后内容消失** (app/[locale]/wishlist/page.tsx)
   - 优化 `useEffect` 依赖项
   - 处理 `wishCards` 异步加载的时序问题
   - 确保刷新后正确恢复内容

4. **优化流式缓冲区日志** (hooks/useStreamingBuffer.ts)
   - 增加 `contentStateRef` 长度输出
   - 便于调试和验证数据完整性
