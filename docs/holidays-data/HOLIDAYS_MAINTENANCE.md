### 详细步骤

#### 阶段 1：数据收集（10月）

**1. 查找官方公告**

```bash
# 参考 docs/HOLIDAYS_DATA_SOURCE.md 中的官方源链接
# 重点关注：
- 中国：国务院办公厅官网
- 美国：联邦储备委员会
- 英国：gov.uk
- 日本：内阁府官网
- 德国：联邦内政部
```

**2. 记录新增或变更**

在 `docs/` 目录创建临时文件：

```markdown
# 2026年节假日变更记录

## 中国
- 春节：2026年2月17日-23日（初一至初七）
- 调休安排：2月14日（周六）、2月28日（周六）上班

## 美国
- 无重大变更（遵循固定规则）

## 英国
- 新增：King's Birthday（待确认日期）
```

## 🐛 错误修复流程

### 发现错误

**来源：**
1. 用户反馈（GitHub Issues）
2. 自我检查
3. 监控告警
4. 官方源变更

### 修复步骤

**示例：修正春节日期错误**

**1. 确认错误**

```markdown
# GitHub Issue #156
**标题**: 2026年春节日期错误

**描述**:
网站显示春节从2月17日开始，但国务院公告是2月18日。

**截图**: [...]
```

**2. 验证官方源**

```bash
# 访问官方网站确认
https://www.gov.cn/zhengce/content/2025-10/xxx.htm

# 确认正确日期：2026-02-18 至 2026-02-24
```

**3. 修改配置文件**

```bash
vim data/holidays/CN.md

# 修改
-### 春节 | Spring Festival
-- **日期**: 2026-02-17 ~ 2026-02-23

+### 春节 | Spring Festival
+- **日期**: 2026-02-18 ~ 2026-02-24
```

**4. 更新维护日志**

```markdown
## 维护日志

- **2025-11-20**: 修正 2026 年春节日期（根据用户反馈 #156）✅
```

**5. 本地测试**

```bash
npm run holidays:validate
npm run dev
# 验证修复正确
```

**6. 提交并部署**

```bash
git add data/holidays/CN.md
git commit -m "fix: 修正 2026 年春节日期

根据国务院办公厅公告，春节应为 2月18日-24日。

Closes #156"

git push origin main
# Vercel 自动部署（约 1-2 分钟生效）
```

**7. 回复 Issue**

```markdown
@username 感谢反馈！

已经修正了 2026 年春节的日期，现在显示为 2月18日-24日。

变更已部署到生产环境，1-2分钟后生效。

参考官方源：[国务院办公厅公告](链接)
```

## ❓ 常见问题处理

### Q1: 如何处理移动假期（如复活节）？

**问题**: 复活节每年日期不同，如何维护？

**解决方案**:

```markdown
# 方案 A：使用算法计算（推荐）
- 使用 Computus 算法预计算未来 4 年
- 官方源验证
- 添加到 Markdown 文件

# 方案 B：API 依赖
- 依赖 Nager.Date API 提供的计算
- 人工验证

# 方案 C：年度手动更新
- 每年从官方源获取
- 逐年添加
```

**实施**:

```typescript
// scripts/calculate-easter.ts
function calculateEaster(year: number): Date {
  // Computus 算法
  const a = year % 19;
  const b = Math.floor(year / 100);
  // ... (完整算法)
  return new Date(year, month, day);
}
```

### Q2: 伊斯兰节日如何处理？

**问题**: 伊斯兰节日基于月相，无法提前2年确定。

**解决方案**:

```markdown
### 开斋节 | Eid al-Fitr
- **日期**: 2026-04-01 ⚠️ 预测值
- **类型**: 宗教节日 (Religious Holiday)
- **全国性**: 是
- **说明**: 
  - ⚠️ 具体日期取决于月相观测
  - 实际日期可能±1-2天
  - 请在节日前查询官方公告
```

### Q3: 各州/省差异如何处理？

**问题**: 德国、印度等国家各州假期不同。

**解决方案**:

```markdown
# 策略：仅维护全国性假期

## 2025年

### Tag der Deutschen Einheit | German Unity Day
- **日期**: 2025-10-03
- **类型**: 公共假期 (Public Holiday)
- **全国性**: 是
- **说明**: 全德共有假期

### Fronleichnam | Corpus Christi
- **日期**: 2025-06-19
- **类型**: 地区假期 (Regional Holiday)
- **全国性**: 否
- **区域**: Baden-Württemberg, Bayern, Hessen, ...
- **说明**: ⚠️ 仅部分州放假
```

### Q4: API 数据与官方源冲突？

**问题**: Nager.Date API 数据与官方源不一致。

**解决方案**:

```markdown
# 优先级原则：官方源 > API

1. 以官方源为准
2. 修改 Markdown 文件
3. 在说明中注明差异
4. 向 Nager.Date 提 Issue
```

**示例**:

```markdown
### 国庆节 | National Day
- **日期**: 2025-10-01, 2025-10-02, 2025-10-03
- **类型**: 公共假期 (Public Holiday)
- **全国性**: 是
- **说明**: 
  - 根据国务院公告，与中秋节连休，共8天
  - ⚠️ Nager.Date API 仅显示3天，已提 Issue #xxx
```

### Q5: 如何批量更新多个国家？

**命令**:

```bash
# 初始化所有国家
npm run holidays:init

# 更新 Tier 1 国家
for country in CN US GB JP DE; do
  npm run holidays:update $country
done

# 更新所有国家
npm run holidays:init
```
