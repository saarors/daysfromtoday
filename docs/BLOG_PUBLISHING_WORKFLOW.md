**版本**: v1.0  
**创建时间**: 2025年10月13日  
**适用范围**: 所有博客内容发布  

## 🎯 流程目标

建立标准化的博客发布流程，确保：
1. 所有博客内容以中文为原始语言
2. 自动生成英文翻译版本
3. 自动更新博客页面，新内容置顶显示
4. 保持内容质量和SEO优化

## 📋 标准发布流程

### 阶段一：中文博客创作
1. **内容创作**
   - 在 `obsidian/content/blog/zh/` 目录下创建中文博客文件
   - 使用标准模板：`blog-template-optimized.md`
   - 确保内容完整、结构清晰、SEO友好

2. **内容检查**
   - 检查文章标题、摘要、标签
   - 验证图片和媒体文件
   - 确认阅读时间估算准确

### 阶段二：英文博客生成
1. **自动翻译**
   - 使用AI工具将中文博客翻译为英文
   - 保持原文结构和格式
   - 调整文化背景和表达方式

2. **翻译质量检查**
   - 确保专业术语翻译准确
   - 检查语法和表达自然度
   - 验证SEO关键词翻译

### 阶段三：博客页面更新
1. **更新博客首页**
   - 修改 `app/[locale]/blog/page.tsx`
   - 将新文章添加到 `blogPosts` 数组
   - 设置 `featured: true` 置顶显示
   - 调整文章顺序，新文章排在第一位

2. **SEO优化**
   - 更新sitemap自动包含新文章
   - 确保所有页面返回200状态码
   - 验证meta标签和结构化数据

### 阶段四：部署和验证
1. **Git提交**
   - 提交所有更改到Git仓库
   - 使用规范的commit信息
   - 推送到远程仓库

2. **生产环境部署**
   - Vercel自动部署
   - 验证生产环境访问正常
   - 检查中英文博客页面显示

3. **最终验证**
   - 测试所有博客页面访问
   - 确认新文章置顶显示
   - 验证SEO和sitemap更新
