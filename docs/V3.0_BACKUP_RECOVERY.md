# V3.0 备份与恢复指南

## 🎯 快速操作手册

### 📦 每日备份（10 秒）

**工作结束前或重要功能完成后，执行**：

```bash
./scripts/v3-backup.sh
```

就这么简单！脚本会自动：
- ✅ 提交未保存的更改
- ✅ 创建时间戳备份分支
- ✅ 显示最近的备份点
- ✅ 自动清理 30 天前的旧备份

---

## 🔄 恢复代码（3 种场景）

### 场景 1: 刚刚误删了文件（最常见）

**恢复到上一次提交**：
```bash
git reset --hard HEAD
```

**恢复单个文件**：
```bash
git checkout HEAD -- path/to/file.tsx
```

---

### 场景 2: 需要回到今天早上的版本

**查看今天的备份**：
```bash
git branch | grep backup-$(date +%Y%m%d)
```

**切换到早上的备份**：
```bash
# 假设显示 backup-20251031-090000
git checkout backup-20251031-090000

# 查看代码，确认无误后创建新分支继续开发
git checkout -b v3.0-dev-recovered
```

---

### 场景 3: 需要回到某个 Phase 完成时的状态

**查看所有备份点**：
```bash
git branch | grep backup
```

**切换到特定备份**：
```bash
# 例如回到 Phase 2.6 完成时
git checkout backup-phase2.6-complete

# 确认无误后
git checkout -b v3.0-dev
```

---

## 🧪 测试恢复能力（建议每周做一次）

**模拟代码丢失并恢复**：

```bash
# 1. 创建测试分支
git checkout -b test-recovery

# 2. 删除一些文件（模拟误删）
rm -rf components/v3/CardGallery.tsx

# 3. 尝试恢复
git checkout HEAD -- components/v3/CardGallery.tsx
# 或
git reset --hard HEAD

# 4. 确认恢复成功后，删除测试分支
git checkout v3.0-dev
git branch -D test-recovery
```

## 🚨 紧急情况处理

### 情况 1: 所有 Git 操作都失败

**可能原因**：`.git` 目录损坏

**解决方案**：
1. 不要 panic
2. 检查 AI 对话历史（Cursor 保存了所有代码）
3. 从对话中复制代码重新创建文件

---

### 情况 2: 不小心删除了备份分支

**查找丢失的提交**：
```bash
git reflog
```

**恢复**：
```bash
# 找到想要恢复的提交 hash
git checkout <commit-hash>
git checkout -b backup-recovered
```

## 💡 最佳实践

### ✅ 推荐的工作习惯

1. **每天开始工作前**：
   ```bash
   git branch backup-$(date +%Y%m%d)-start
   ```

2. **重要功能完成后**：
   ```bash
   ./scripts/v3-backup.sh
   ```

3. **每天工作结束前**：
   ```bash
   ./scripts/v3-backup.sh
   ```

4. **每周一次**：
   - 查看备份点：`git branch | grep backup`
   - 清理本地缓存：`rm -rf .next && rm -rf node_modules/.cache`

---

### ❌ 需要避免的操作

1. **永远不要用 `git clean -fd`**
   - 如果一定要清理，先用 `-n` 预览：`git clean -fd -n`
   - 或者先备份：`./scripts/v3-backup.sh`

2. **不要直接在 main 分支开发 V3.0**
   - 始终在 `v3.0-dev` 分支工作
   - 完成后再合并到 main

3. **不要删除近期的备份分支**
   - 脚本会自动清理 30 天前的备份
   - 不需要手动删除

## 🎓 Git 命令速查

```bash
# 查看当前分支
git branch --show-current

# 查看所有分支
git branch -a

# 查看未提交的更改
git status

# 查看提交历史
git log --oneline -10

# 回滚到上次提交
git reset --hard HEAD

# 切换分支
git checkout <branch-name>

# 创建并切换到新分支
git checkout -b <branch-name>

# 查看两个分支的差异
git diff branch1 branch2

# 恢复单个文件
git checkout HEAD -- <file-path>
```
