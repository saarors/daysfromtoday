## 🐛 已修复的问题

### Bug #1: Hydration 错误 ✅
**问题**：服务端渲染 "0 张卡片"，客户端显示 "1 张卡片"  
**原因**：LocalStorage 仅在客户端可用  
**解决**：添加 `mounted` 状态，SSR 时显示 0

### Bug #2: @vercel/og 渲染错误 ✅
**问题**：`Expected <div> to have explicit "display: flex"`  
**原因**：Satori 要求显式声明 display  
**解决**：所有 div 添加 `display: 'flex'`，移除 `zIndex`
