# 🤖 常用 AI Prompt 模板

## 模板一：生成页面/组件

目标：{描述页面目的}

输入参数：{n, locale, mode 等}

要求：

* 遵守现有依赖；
* 保留 i18n/SEO/CWV；
* 不新增第三方库。
  输出格式：

1. 文件清单与路径
2. 完整代码（含注释）
3. 测试与验收步骤

## 模板二：代码重构与风险评估

任务：请审查以下改动的影响。

输出：

* 风险等级（高/中/低）
* 影响范围（SEO/性能/安全）
* 建议或替代方案
* 回滚方案

## 模板三：性能优化请求

请优化以下模块以满足 CWV 指标。

要求：

* LCP≤2.5s、INP≤200ms、CLS≤0.1；
* 不改变业务逻辑；
* 提供前后性能对比。
