# 🛡️ 项目护栏（Guardrails）

## 一、依赖与安全

- 非必要不新增依赖；
- 新增需说明体积、来源、替代方案、风险；
- 所有第三方库必须 MIT / Apache 2.0 开源协议；
- 不允许引入跟踪脚本（除 AdSense 官方代码）。

## 二、隐私与合规

- 默认不存储 IP、用户信息；
- 所有外部请求必须说明来源；
- CSP 改动需先使用 Report-Only；
- Cloudflare 保持灰云（DNS Only）。

## 三、AI 改动规则

- 若 AI 对代码结构有疑问，先输出“待确认列表 (To Confirm)”；
- 对 SEO / 性能 / 安全的影响必须提前评估；
- 未确认风险时不得自动改写全局配置；
- 遇到歧义，优先遵守 docs/ai 规范。
