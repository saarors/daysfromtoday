#### 技术要点
```typescript
// app/api/ai/chat/route.ts
export async function POST(request: Request) {
  const { goalText, days, targetDate, assistant, locale } = await request.json();
  
  // 根据 assistant 选择不同的 system prompt
  const systemPrompt = getSystemPrompt(assistant, locale);
  
  // 调用 DeepSeek API
  const response = await fetch('https://api.deepseek.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.DEEPSEEK_API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [
        { role: 'system', content: systemPrompt },
        { role: 'user', content: `目标: ${goalText}\n天数: ${days}\n目标日期: ${targetDate}` }
      ],
      stream: true,
    }),
  });
  
  return new Response(response.body, {
    headers: { 'Content-Type': 'text/event-stream' },
  });
}
```

#### 估计时间：2-3 天
#### 验收标准：
- ✅ AI 回复内容符合助手风格
- ✅ 流式响应流畅，无卡顿
- ✅ 错误处理完善（API 限流、超时、失败降级）

#### 技术要点
```typescript
// app/api/ai/image/route.ts
export async function POST(request: Request) {
  const { goalText, aiSummary } = await request.json();
  
  // 生成图片 prompt
  const imagePrompt = generateImagePrompt(goalText, aiSummary);
  
  // 调用 DALL-E 3 API
  const response = await fetch('https://api.openai.com/v1/images/generations', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.OPENAI_API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: 'dall-e-3',
      prompt: imagePrompt,
      n: 1,
      size: '1024x1024',
      quality: 'standard',
    }),
  });
  
  const data = await response.json();
  const imageUrl = data.data[0].url;
  
  // 上传到 Supabase Storage
  const storedUrl = await uploadToSupabase(imageUrl);
  
  return Response.json({ imageUrl: storedUrl });
}
```

#### 估计时间：2-3 天
#### 验收标准：
- ✅ 图片生成成功，与目标相关
- ✅ 图片存储在 Supabase，永久可访问
- ✅ 异步处理，不阻塞用户操作

```typescript
// lib/rate-limit.ts
import { Ratelimit } from '@upstash/ratelimit';
import { Redis } from '@upstash/redis';

const ratelimit = new Ratelimit({
  redis: Redis.fromEnv(),
  limiter: Ratelimit.slidingWindow(5, '1 d'), // 每天 5 次
  analytics: true,
});

export async function checkRateLimit(userId: string) {
  const { success } = await ratelimit.limit(userId);
  return success;
}
```

## 💰 成本预估

### DeepSeek API
- **模型**: `deepseek-chat`
- **价格**: ¥0.001 / 1K tokens (输入), ¥0.002 / 1K tokens (输出)
- **预估**: 每次对话 ~500 tokens 输入 + 1000 tokens 输出 = ¥0.0025 / 次
- **月成本** (1000 用户，每人 5 次): ¥12.5

### DALL-E 3 API
- **模型**: `dall-e-3` (1024x1024, standard)
- **价格**: $0.040 / 张 (约 ¥0.29)
- **月成本** (1000 用户，每人 1 张): ¥290

### Supabase Storage
- **价格**: 1GB 免费，超出 $0.021/GB
- **预估**: 1000 张图片 ~1GB，免费额度内

### 总成本预估
- **月成本**: ~¥302.5 (1000 活跃用户)
- **单用户成本**: ~¥0.3
