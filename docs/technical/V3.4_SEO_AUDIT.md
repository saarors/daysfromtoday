## ⚠️ 需要优化的地方

### 1. 页面结构问题 (7/10)

#### ❌ 列表页缺少结构化标签
**当前问题**:
```tsx
<section className="text-center mb-12">
  <h1>愿望宝典</h1>
  <p>用时间记录人类目标与实现之路</p>
</section>
<section className="mb-8">
  {/* 筛选器 */}
</section>
<div className="grid">
  {/* 卡片 */}
</div>
```

**建议优化**:
```tsx
<main>
  <header>
    <h1>愿望宝典</h1>
    <p>用时间记录人类目标与实现之路</p>
  </header>
  
  <nav aria-label="筛选器">
    {/* 筛选器 */}
  </nav>
  
  <section aria-label="愿望卡片列表">
    <div className="grid">
      {/* 卡片 */}
    </div>
  </section>
</main>
```

#### ❌ 详情页缺少 Schema.org 结构化数据
**建议添加 JSON-LD**:
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "200天，我从只能跑500米到能跑半马",
  "description": "0基础如何跑半马",
  "author": {
    "@type": "Organization",
    "name": "DaysFromToday"
  },
  "publisher": {
    "@type": "Organization",
    "name": "DaysFromToday",
    "logo": {
      "@type": "ImageObject",
      "url": "https://www.daysfromtoday.ai/logo.png"
    }
  },
  "datePublished": "2025-01-07",
  "dateModified": "2025-01-07",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://www.daysfromtoday.ai/zh/wish-books/200-days-run"
  }
}
```

#### ❌ 缺少面包屑导航（Breadcrumbs）
**当前**: 只有简单的返回链接
```tsx
<Link href={`/${locale}/wish-books`}>← 返回愿望宝典</Link>
```

**建议**: 完整的面包屑导航
```tsx
<nav aria-label="面包屑" itemScope itemType="https://schema.org/BreadcrumbList">
  <ol>
    <li itemProp="itemListElement" itemScope itemType="https://schema.org/ListItem">
      <Link href="/" itemProp="item">首页</Link>
      <meta itemProp="position" content="1" />
    </li>
    <li itemProp="itemListElement" itemScope itemType="https://schema.org/ListItem">
      <Link href="/zh/wish-books" itemProp="item">愿望宝典</Link>
      <meta itemProp="position" content="2" />
    </li>
    <li itemProp="itemListElement" itemScope itemType="https://schema.org/ListItem">
      <span itemProp="item">200天，我从只能跑500米到能跑半马</span>
      <meta itemProp="position" content="3" />
    </li>
  </ol>
</nav>
```

### 2. 页面内容问题 (6/10)

#### ❌ 标题层级不规范
**当前问题**:
- 列表页：H1 → 直接到卡片内容，缺少 H2、H3
- 详情页：H1 → H2（跳过了中间层级）

**建议**:
```tsx
// 列表页
<h1>愿望宝典</h1>
<h2>筛选您的目标</h2>
<h3>热门类别</h3>
<h3>推荐时长</h3>

// 详情页
<h1>200天，我从只能跑500米到能跑半马</h1>
<h2>故事开始</h2>
<h3>第一阶段：适应训练</h3>
<h3>第二阶段：增强耐力</h3>
```

#### ❌ 图片缺少 alt 属性
**当前**: 封面图没有 alt 文本
```tsx
<div style={{ backgroundImage: `url(${book.cover_image_url})` }}></div>
```

**建议**: 使用 `<Image>` 组件或添加 alt
```tsx
<Image 
  src={book.cover_image_url} 
  alt={book.title} 
  width={800} 
  height={400}
/>
```

#### ❌ 内容密度不足
**当前**: 详情页可能只有标题和简介，内容过少
- story_intro: 可选
- content_html: 可选
- 如果两者都为空，显示"内容正在完善中..."

**建议**: 确保每页至少有 300 字以上的实质性内容

## 🎯 SEO 改进建议

### 内容策略
1. **确保内容质量**: 每张卡片至少 500-800 字

2. **移动优先**: 响应式设计

2. **外部链接**: 引用权威来源
