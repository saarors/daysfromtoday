## ❓ 常见问题

### Q1: Console 中看到 `fallback_level: 1` 或 `fallback_level: 2`

**原因**: 
- Level 1: 数据库中没有精确匹配的 Prompt，使用了通用模板
- Level 2: 数据库查询失败，使用了硬编码降级

**解决方案**:
```sql
-- 检查 Prompt 库覆盖情况
SELECT goal_type, difficulty, language, stage, is_active
FROM ai_prompt_library
ORDER BY goal_type, difficulty;

-- 如果缺少某些组合，添加新的 Prompt 模板
INSERT INTO ai_prompt_library (...)
VALUES (...);
```

### Q2: Console 中看到 `has_methodology: false`

**原因**: 
- Prompt 模板没有关联方法论
- 或者方法论匹配失败

**解决方案**:
```sql
-- 检查方法论库
SELECT code, name_zh, applicable_goal_types, is_active
FROM methodology_library;

-- 检查 Prompt 是否关联了方法论
SELECT id, goal_type, difficulty, methodology_id
FROM ai_prompt_library;

-- 更新 Prompt，关联方法论
UPDATE ai_prompt_library
SET methodology_id = (SELECT id FROM methodology_library WHERE code = 'smart')
WHERE goal_type = 'general' AND difficulty = 'easy';
```

### Q3: API 返回 500 错误

**原因**: 
- 数据库连接失败
- DeepSeek API Key 未配置
- 代码逻辑错误

**排查步骤**:
1. 检查 Console 中的完整错误日志
2. 检查环境变量:
   ```bash
   echo $DEEPSEEK_API_KEY
   ```
3. 检查数据库连接:
   ```sql
   SELECT 1; -- 测试连接
   ```
4. 如果是代码错误，立即回滚到旧版

### Q4: 内容生成质量下降

**原因**: 
- 新的 Prompt 可能不如旧版优化
- 方法论注入可能干扰了原有逻辑

**解决方案**:
1. **临时方案**: 切换回旧版
   ```typescript
   useV3Prompts: false
   ```

2. **长期方案**: 优化 Prompt 模板
   ```sql
   -- 更新 Prompt 内容
   UPDATE ai_prompt_library
   SET system_prompt = '优化后的内容'
   WHERE goal_type = '...' AND difficulty = '...';
   ```
