## 五、常见问题

### Q1: 执行脚本时报错 "relation already exists"

**原因**: 表已经存在

**解决方案**:
```sql
-- 方案1: 删除已存在的表（如果确认可以删除）
DROP TABLE IF EXISTS ai_prompt_library CASCADE;
-- 然后重新执行创建脚本

-- 方案2: 修改脚本中的表名
-- 例如: ai_prompt_library_v2
```

### Q2: 插入种子数据时报错 "foreign key violation"

**原因**: methodology_library 表中没有对应的记录

**解决方案**:
1. 确认 methodology_library 表已创建并插入数据
2. 检查外键引用是否正确
3. 按顺序执行: 先创建表 → 再插入方法论 → 最后插入 Prompt

### Q3: 如何查看详细的错误信息？

**Supabase SQL Editor**:
- 错误会显示在查询结果下方
- 包含错误行号和具体原因

**PostgreSQL 错误日志**:
```sql
-- 查看最近的错误日志
SELECT * FROM pg_stat_statements 
WHERE query LIKE '%ai_prompt%' 
ORDER BY calls DESC 
LIMIT 10;
```

### Q4: 数据插入后，如何修改某个方法论的内容？

```sql
-- 示例: 修改"渐进式超负荷"的描述
UPDATE methodology_library
SET description_zh = '新的描述内容'
WHERE code = 'progressive-overload';

-- 查看修改结果
SELECT * FROM methodology_library 
WHERE code = 'progressive-overload';
```

### Q5: 如何添加新的方法论？

```sql
-- 参考现有记录的格式
INSERT INTO methodology_library (
  code, name_zh, name_en,
  description_zh, description_en,
  principles,
  applicable_goal_types,
  min_difficulty_level, max_difficulty_level,
  prompt_injection_zh, prompt_injection_en,
  priority, source, tags
) VALUES (
  'your-methodology-code',
  '中文名称',
  'English Name',
  '中文描述',
  'English description',
  '["原则1", "原则2"]',
  '{"goal_type1", "goal_type2"}',
  1, 4,
  'Prompt 注入内容（中文）',
  'Prompt injection content (English)',
  5,
  '来源',
  '{"tag1", "tag2"}'
);
```
