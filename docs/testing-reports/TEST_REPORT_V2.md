## 🐛 已知问题

### 问题列表

| ID | 问题描述 | 严重程度 | 状态 | 预计修复 |
|----|---------|---------|------|---------|
| 1 | 部分节假日中文翻译不够准确 | 低 | 🔧 待优化 | v2.1 |
| 2 | 缺少节假日调休信息 | 中 | 🔧 待添加 | v2.1 |

| 4 | Tier 1 国家数据待人工验证 | 中 | ⏳ 进行中 | v2.1 |

### 详细说明

#### 问题 1: 部分节假日中文翻译不够准确

**示例:**
```
❌ "Chinese New Year (Spring Festival)" → "Chinese 新年 (Spring Festival)"
✅ 应为: "春节"
```

**影响:** 用户体验略有影响，但不影响功能
**优先级:** P2（低）
**修复方案:** 人工优化翻译词典

#### 问题 2: 缺少节假日调休信息

**示例:**
```
当前: 2025-01-01: 元旦
理想: 2025-01-01: 元旦（调休3天：1月1日-1月3日）
```

**影响:** 用户无法了解完整的放假安排
**优先级:** P1（中）
**修复方案:** 在 Markdown 配置中添加详细说明

#### 问题 3: AE（阿联酋）节假日数据为空

**原因:** Nager.Date API 返回空数据
**影响:** 阿联酋用户无法查看节假日
**优先级:** P3（低）
**修复方案:** 手动从官方源添加数据

#### 问题 4: Tier 1 国家数据待人工验证

**状态:** 当前使用 API 生成的初始数据
**影响:** 数据准确性可能存在偏差
**优先级:** P1（中）
**修复方案:** 按计划进行人工验证
