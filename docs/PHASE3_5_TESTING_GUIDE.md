| 难度评估 | EASY / MEDIUM | 90天减10斤属于合理难度 |

1. 制定饮食计划

1-5 条具体建议

- ✅ Markdown 格式正确渲染

## 🐛 常见问题排查

### 问题 1：匹配结果不显示

**原因：** 可能是匹配函数返回 null

**检查：**
```javascript
console.log('🎯 AI 匹配结果:', matchResult);
```

**解决：**
- 确认 `goal_types` 表有数据
- 确认 `ai_personas` 表有数据
- 检查 Supabase 连接

### 问题 2：AI 生成失败

**原因：** DeepSeek API 调用失败

**检查：**
```bash
# 测试 API
npx tsx scripts/test-deepseek-api.ts
```

**解决：**
- 检查 `DEEPSEEK_API_KEY` 环境变量
- 检查网络连接
- 查看 API 日志

### 问题 3：重复保存

**原因：** React Strict Mode 双重调用

**检查：**
- 是否使用了 `savingRef.current` 锁
- 是否有重复卡片检测

**解决：**
- 已在代码中实现「三重保护」机制
